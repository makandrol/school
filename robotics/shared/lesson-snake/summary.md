# Спільний урок: 🐍 Гра «Змійка» на micro:bit
**Дата:** 21.04.2026 (5-АБ) / 23.04.2026 (5-ВГ)
**Статус:** ✅ Створено

## Тема
Класична гра «Змійка» на LED-матриці 5×5. Масиви для зберігання тіла змійки, різні варіанти керування та поведінки на межах поля.

## Нові концепції
- Масив (array) як структура для зберігання тіла змійки
- `array of ...` / `list` — створення та зміна масиву
- `get value at` / `insert at` / `remove last` — робота з елементами масиву
- `remainder of` (%) — прохід через стінки (wrap-around)
- `led.plotBrightness(x, y, brightness)` — різна яскравість для їжі (блимання)
- Акселерометр (`acceleration (mg) x/y`) — альтернативне керування нахилом

## Як працює змійка

### Структура даних
- Масив пар координат: [голова, ..., хвіст]
- Змінні: `напрямокX`, `напрямокY` — вектор руху (−1, 0, +1)
- Змінна `довжина` — поточна довжина змійки
- Координати їжі: `їжаX`, `їжаY`

### Ігровий цикл (forever)
1. Обчислити нову позицію голови: `головаX + напрямокX`, `головаY + напрямокY`
2. Перевірити межі (прохід через стінки АБО кінець гри)
3. Перевірити зіткнення з собою → кінець гри
4. Перевірити чи з'їли їжу → довжина + 1, нова їжа, звук
5. Видалити хвіст (якщо не з'їли їжу)
6. Додати нову голову
7. Очистити екран → намалювати всю змійку та їжу
8. Пауза (швидкість гри)

## Що зробили

### Крок 1 — Базова змійка з кнопками A/B
- **Керування:** A = поворот вліво, B = поворот вправо (відносно поточного напрямку)
- **Межі:** прохід через стінки (wrap-around через `remainder of`)
- **Їжа:** блимає (toggle в forever-циклі)
- **Кінець:** зіткнення з собою → show number довжина
- Масив `тіло` зберігає позиції у форматі `x * 5 + y`
- Функції: `новаЇжа`, `намалювати`, `кінецьГри`

### Крок 2 — Смерть від стінок (якщо залишився час)
- Замість wrap-around: якщо `головаX < 0` або `> 4` → кінець гри
- Додаємо перевірку в основний цикл
- Змінна-прапорець `стінкиВбивають` (можна перемикати)

### Крок 3 — Керування нахилом (якщо залишився час)
- `acceleration (mg) x` та `acceleration (mg) y` замість кнопок
- Якщо нахил > 300 → змінити напрямок відповідно
- Більш інтуїтивне керування

### Крок 4 — Звуки (якщо залишився час)
- При підборі їжі: `play tone Middle C for 1/8 beat`
- При кінці гри: `play melody dadadum`

## MakeCode блоки
- `Array.create()` / `list` (Arrays) — створення масиву
- `list.insertAt(0, value)` / `list.push(value)` (Arrays) — додати елемент
- `list.removeAt(index)` / `list.pop()` (Arrays) — видалити елемент
- `list.get(index)` / `list[index]` (Arrays) — отримати елемент
- `list.length` (Arrays) — довжина масиву
- `list.indexOf(value)` (Arrays) — пошук елемента (для перевірки зіткнення з собою)
- `remainder of` (Math) — остача від ділення (wrap-around)
- `led.plotBrightness(x, y, brightness)` (Led → more) — яскравість 0–255
- `acceleration (mg) x/y` (Input → more) — дані акселерометра
- `play tone` (Music) — звукові ефекти
