🐍 Гра «Змійка» на micro:bit 🐍

Привіт! Сьогодні створюємо класичну гру «Змійка» на LED-дисплеї 5×5! 🎮

---

🐍 КРОК 1 — Базова змійка (кнопки A/B, прохід через стінки)

📋 Створюємо змійку яка рухається, їсть і росте!

Керування:
• A → поворот вліво (відносно напрямку руху)
• B → поворот вправо (відносно напрямку руху)

Що потрібно:
• Масив `тіло` — зберігає позиції всіх частин змійки (кожна позиція = x × 5 + y)
• Змінні `напрямокX` та `напрямокY` — куди рухається змійка
• Змінні `їжаX` та `їжаY` — де знаходиться їжа

Як працює:
1. Кожен крок: нова позиція голови = стара + напрямок
2. Якщо вийшли за межі → з'являємось з іншого боку (remainder of)
3. Якщо голова на їжі → довжина +1, нова їжа
4. Якщо голова на тілі → кінець гри, показати довжину
5. Їжа блимає (plotBrightness міняється) щоб було видно!

Функції:
• `новаЇжа` — випадкова позиція, не на тілі змійки
• `намалювати` — очистити екран, намалювати тіло та їжу
• `кінецьГри` — показати довжину, зупинити гру

💡 Поворот: коли натискаєш A, напрямок повертається на 90° вліво. Якщо їхали вправо (1,0) → тепер їдемо вгору (0,-1)

---

🧱 КРОК 2 — Смерть від стінок (якщо залишився час)

📋 Змійка гине при зіткненні зі стінкою!

Що змінити:
• Замість remainder of → перевірка: якщо головаX < 0 або > 4 → кінець гри!
• Так само для головаY
• Гра стає набагато складнішою!

---

📱 КРОК 3 — Керування нахилом (якщо залишився час)

📋 Нахиляй micro:bit замість кнопок!

Що змінити:
• Використовуємо acceleration (mg) x та acceleration (mg) y
• Нахил вправо (x > 300) → напрямокX = 1, напрямокY = 0
• Нахил вліво (x < −300) → напрямокX = −1, напрямокY = 0
• Нахил вперед (y > 300) → напрямокX = 0, напрямокY = 1
• Нахил назад (y < −300) → напрямокX = 0, напрямокY = −1

---

🔊 КРОК 4 — Звуки (якщо залишився час)

📋 Додаємо звукові ефекти!

• При підборі їжі: play tone Middle C for 1/8 beat
• При кінці гри: play melody dadadum
