🎲 Математичні задачі та гральний кубик 🎲

Привіт! Сьогодні micro:bit стає математиком! 🧮

---

⭐ ЗАВДАННЯ 1 — «Гральний кубик» 🎲
📋 Струсни micro:bit — побач грань кубика!

Що робити:
• on shake → випадкове число 1–6
• Для кожного числа — show leds з крапками (як на справжньому кубику!)
• Перед результатом — анімація кидка (2-3 випадкових патерни з паузою 100мс)

Створи функцію `показатиГрань`:
• if грань = 1 → show leds (1 крапка по центру)
• if грань = 2 → show leds (2 крапки по діагоналі)
• ... і так до 6!

---

⭐⭐ ЗАВДАННЯ 2 — «Два кубики» 🎲🎲
📋 Кинь два кубики та порахуй суму!

• A → кинути кубик 1 (показати грань)
• B → кинути кубик 2 (показати грань)
• A+B → показати суму двох кубиків
• Сума = 7 або 11 → БОНУС! 😊 +1 бал!
• Shake → скинути бали

Функції: `кинутиКубик1`, `кинутиКубик2`, `показатиСуму`

---

⭐⭐⭐ ЗАВДАННЯ 3 — «Математичний тренажер» 🧮
📋 micro:bit задає приклад — ти відповідаєш кнопками!

Як грати:
• Екран показує задачу: «3+5=»
• A → зменшити відповідь на 1
• B → збільшити відповідь на 1
• A+B → підтвердити!
• ✅ Правильно → 😊 + бал + нова задача
• ❌ Неправильно → 😢 + правильна відповідь

Функції:
• `новаЗадача` — a, b = random 1–9, операція (+ або −)
• `показатиЗадачу` — join a + знак + b + "="
• `перевірити` — порівняти з правильною відповіддю

💡 Блок join (Text) — склеює текст! "3" + "+" + "5" + "=" → "3+5="

---

⭐⭐⭐⭐ ЗАВДАННЯ 4 — «Математичний спринт» ⏱️
📋 10 задач на час! Хто розв'яже швидше?

• Таймер починається з першою задачею (running time)
• 10 задач підряд (+ та −)
• Правильно → наступна задача
• Неправильно → та сама задача знову
• Після 10-ї → показати час у секундах та кількість правильних з першого разу
• Shake → нова гра!

⏱️ running time (мс) ÷ 1000 = секунди!
