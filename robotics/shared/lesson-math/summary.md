# Спільний урок: 🎲 Математичні задачі та гральний кубик
**Дата:** 14.04.2026 (5-АБ) / 16.04.2026 (5-ВГ)
**Статус:** ✅ Створено

## Тема
Математичні операції в MakeCode: випадкові числа, арифметика, показ результатів. Перехід від ігор до практичних програм.

## Нові концепції
- Математичні операції в MakeCode: +, −, ×, ÷, остача (%)
- `show leds` для малювання кубикових граней (замість show number)
- Збереження найкращого результату (змінна `рекорд`)
- Таймер з `running time`
- Масив як сховище задач

## Що зробили

### ⭐ Завдання 1 — «Гральний кубик» 🎲
- Механіка: shake → випадкове 1–6 → показати грань кубика
- `on shake` → `set грань = pick random 1 to 6`
- if/else if: для кожного числа — `show leds` з відповідним патерном крапок
- Функція `показатиГрань`: малює 1–6 крапок через show leds
- Анімація кидка: 3× show leds (випадкові патерни) з паузою 100мс перед результатом

### ⭐⭐ Завдання 2 — «Два кубики» 🎲🎲
- A = кинути кубик 1, B = кинути кубик 2, A+B = показати суму
- Змінні: кубик1, кубик2, сума
- Функції: `кинутиКубик1`, `кинутиКубик2`, `показатиСуму`
- Якщо сума = 7 або 11 → бонусна анімація (show icon Happy) + змінити бали на 1
- shake = скинути бали

### ⭐⭐⭐ Завдання 3 — «Математичний тренажер» 🧮
- Механіка: micro:bit показує задачу "a + b = ?", гравець вводить відповідь кнопками
- Генерація: a = random 1–9, b = random 1–9, операція = random 0–1 (+ або −)
- Показ: show string "3+5=" (склеюємо число + знак + число + "=")
- Введення відповіді: A = −1, B = +1, A+B = підтвердити. show number поточна_відповідь
- Перевірка: якщо відповідь правильна → show icon Happy + бал, інакше → show icon Sad + show number правильна
- Функція `новаЗадача`: генерує a, b, операцію, обчислює правильну відповідь
- Функція `перевіритиВідповідь`: порівняння
- forever-цикл: показ поточної відповіді поки не підтвердив

### ⭐⭐⭐⭐ Завдання 4 — «Математичний спринт» ⏱️
- Механіка: 10 задач на час! Хто розв'яже швидше?
- Змінні: задача_номер, правильних, старт_час
- На початку: задача_номер = 1, правильних = 0, записуємо running time
- Кожна правильна відповідь → задача_номер + 1, правильних + 1, нова задача
- Після 10 задач → показати час (running time − старт_час) та кількість правильних
- Функція `показатиРезультат`: час у секундах (÷ 1000) + кількість правильних
- shake = почати заново

## MakeCode блоки
- Math: `+`, `−`, `×`, `÷`, `remainder of`
- `pick random 0 to N` (Math)
- `show leds` (Basic) — для граней кубика
- `show number`, `show string`, `show icon` (Basic)
- `join` (Text) — для склеювання рядків
- `running time (ms)` (Input → more)
- `function`, `call function` (Functions)
- `if/else if`, `and`, `or` (Logic)
- `on shake`, `on button A/B/A+B pressed` (Input)
