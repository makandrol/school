# Урок 8: 🐣 Великодні функції у MakeCode
**Дата:** 09.04.2026
**Статус:** ✅ Створено

## Тема
Функції в MakeCode через великодню тематику: створення, виклик, рефакторинг попередніх ігор. Українські великодні традиції.

## Що вивчили
- Що таке функція (аналогія: рецепт)
- Категорія «Розширені → Функції»
- Блоки: `функція назваФункції`, `викликати назваФункції`
- Рефакторинг: винесення повторюваного коду у функцію
- Функція може викликати іншу функцію

## Що зробили

### ⭐ Завдання 1 — Великодне привітання з функцією:
- Функція `привітання`: показати ♥ → пауза 500 → показати рядок "ХВ" → пауза 500 → очистити
- Викликається з: on button A, on button B, on shake
- Ключова ідея: зміна всередині функції — зміна скрізь

### ⭐⭐ Завдання 2 — Машинка-кошик з функцією перевіритиКордони:
- Рефакторинг гри «Машинка» — тепер це великодній кошик, що збирає писанки
- Функція `перевіритиКордони`: if x > 4 → set x to 4, if x < 0 → set x to 0
- Кнопки A/B: change x + call перевіритиКордони
- Порівняння: до (повтор) vs після (функція)

### ⭐⭐⭐ Завдання 3 — Збирач писанок з функціями:
- Функція `новаПисанка`: set писанкаX = random 0-4, set писанкаY = random 0-4
- Функція `перевіритиЗбір`: if x=писанкаX and y=писанкаY → score +1, call новаПисанка
- Демонстрація: функція може викликати іншу функцію

## MakeCode блоки
- `function`, `call function` (категорія Functions/Advanced)
- Всі попередні блоки: plot, unplot, clear screen, variables, if/else, buttons, etc.
