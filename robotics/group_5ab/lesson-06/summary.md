# Урок 25: 🐣 Великодні функції — закріплення
**Дата:** 07.04.2026
**Статус:** ✅ Створено

## Тема
Закріплення роботи з функціями через 4 великодні проєкти з різними ігровими механіками. Тематика — Великдень в Україні.

## Що закріпили
- Створення та виклик функцій (категорія Розширені → Функції)
- Одна функція — багато місць виклику
- Функція може викликати іншу функцію
- Організація коду через функції

## Що зробили

### ⭐ Завдання 1 — «Великодній кошик» 🧺:
- Механіка: випадкове вітання з кількох подій
- Функція `показатиВітання`: випадкове число 0–4 → if/else if → різні іконки (♥, «ХВ», ★, 😊, ✿) → пауза → очистити
- Викликається з: on shake, on button A, on button B
- Ключова ідея: одна функція, три точки виклику

### ⭐⭐ Завдання 2 — «Пошук писанок» 🥚:
- Механіка: 2D-навігація по сітці (гравець рухається вільно в 4 напрямках)
- Гравець (яскрава точка) ходить по LED-екрану: A = вліво, B = вправо, A+B = вниз, shake = вгору
- Писанка з'являється у випадковому місці — дійди до неї!
- Функції: `новаПисанка` (випадкові x,y), `перевіритиКордони` (для x і y), `перевіритиЗбір` (координати збігаються?), `намалювати`
- Кожні 3 писанки — бонусна анімація через функцію `святковаАнімація`

### ⭐⭐⭐ Завдання 3 — «Великодній дзвін» 🔔:
- Механіка: гра на реакцію/таймінг
- Екран показує зворотний відлік (5→4→3→2→1→🔔), потім вмикається «дзвін» (LED мигає)
- Гравець натискає A+B якнайшвидше! Час реакції = бали
- Функції: `показатиВідлік` (анімація цифр), `запуститиДзвін` (включає мигання), `перевіритиРеакцію` (порівняння часу), `показатиРезультат`
- 3 раунди, найкращий результат зберігається через змінну

### ⭐⭐⭐⭐ Завдання 4 — «Писанковий змій» 🐍🥚:
- Механіка: класичний Snake — змійка росте, збираючи писанки
- Змійка — масив координат (голова рухається, хвіст стирається)
- Функції: `рухЗмійки` (зміна напрямку голови), `перевіритиЗбір` (голова на писанці → ріст), `перевіритиКінець` (голова за межами або вкусила себе), `намалювати` (clear + plot всіх точок)
- A = повернути вліво, B = повернути вправо (відносно напрямку)
- Game Over при виході за межі

## MakeCode блоки
- `function`, `call function` (Functions/Advanced)
- `plot x y`, `unplot x y`, `clear screen` (LED)
- `pick random`, `show number`, `show string`, `show icon` (Basic/Math)
- `forever`, `pause`, `if/else`, `and`, `or` (Logic/Loops)
- `running time (ms)` (Input/more)
- Arrays: `add value to end`, `get value at`, `length of array` (для змійки)

## Самостійна робота
- Додати звукові ефекти через функції
- У «Пошуку писанок» — додати перешкоди
- У «Змійці» — додати рівні складності через функцію `наступнийРівень`
