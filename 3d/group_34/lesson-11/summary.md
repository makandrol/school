# Заняття 11: 🖨️ Моделі для 3D-друку
**Дата:** 28.04.2026
**Статус:** ✅ Створено

## Тема
Проєктування моделей, які будуть надруковані на 3D-принтері. Кожен учень обирає одну з 4 моделей, моделює і отримає роздруківку (~7–10 см).

## Особливості моделювання для друку
- **Товщина стінок** мінімум 2 мм (тонше — зламається)
- **Плоска основа** — модель має стійко стояти на столі (нижня частина = площина)
- **Без нависань > 45°** або з підтримками
- **Об'єднати все в Group** перед експортом (одна суцільна модель)
- **Розмір** ~7–10 см (70–100 мм) по найбільшій стороні

## Що зробили

### ⭐ Завдання 1 — Брелок з ім'ям 🔑
- Основа: Box (40×18×4) з закругленими краями — або Cylinder сплющений
- Отвір для кільця: Cylinder Hole (⌀4) в одному кутку
- Ім'я: Text 3D (висота 3мм) — ім'я учня, зверху на основі
- Декор: маленька фігурка збоку (зірочка, серце, або улюблена форма)
- Товщина тексту ≥ 2мм щоб надрукувався
- ~6 елементів

### ⭐⭐ Завдання 2 — Підставка для телефону 📱
- Основа: Box (50×40×5) — стійка платформа
- Спинка: Box (50×5×45), нахилена назад на ~15°
- Виріз для телефону: Box Hole (44×8×3) внизу спинки — тримач
- Виріз для кабелю: Box Hole (10×10×5) по центру знизу
- Ім'я: Text 3D на спинці
- Декор: ажурний візерунок на спинці (Cylinder Hole або фігурні вирізи)
- ~12 елементів

### ⭐⭐⭐ Завдання 3 — Дзига (spinning top) 🌀
- Корпус: Cone (⌀40, H=15) — основна частина (широка зверху, вузька знизу)
- Вістря: Sphere (⌀6) або Cone маленький знизу — на чому крутиться
- Ручка: Cylinder (⌀8, H=12) зверху по центру — за що крутити
- Декор: 4–6 заглиблень на верхній площині (Cylinder Hole, Ctrl+D по колу)
- Або: 3 лопаті (Box, Ctrl+D 120°) замість суцільного конуса
- Варіант: Half Sphere замість Cone = іншій баланс
- ~10 елементів

### ⭐⭐⭐⭐ Завдання 4 — Стаканчик-звірятко 🐸
- Стакан: Cylinder (⌀40, H=50) − Cylinder Hole (⌀36, H=47) → порожній стакан
- Вибір тварини (жаба/кіт/сова/робот):
  - Очі: 2 × Sphere або Cylinder на зовнішній стінці
  - Зіниці: 2 × Cylinder Hole (або менші Sphere чорні)
  - Рот: Box Hole або Torus (посмішка)
  - Вуха/роги/очі що стирчать: Sphere/Cone/Box зверху
- Лапки: 2 × Sphere сплющені внизу (ніжки стаканчика)
- Можна текст ззаду (ім'я)
- ~18 елементів

## Важливо перед експортом
1. Виділити все → Ctrl+G (Group) — одна суцільна модель
2. Export → STL
3. Перевірити розмір: найбільша сторона ~80мм

## Tinkercad фігури
Box, Cylinder, Sphere, Cone, Half Sphere, Text, Torus, Hole-версії
