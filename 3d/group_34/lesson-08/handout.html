⭐ Розписана писанка 🥚 6 елементів
Sphere 20×20×28 (червона) + 3 Cylinder-смужки (жовті, H=1) + 6 Box-ромбиків (45°) + зірочка (2 Box хрестом) + підставка (Cylinder − Hole → кільце)
⭐⭐ Кошик з дарунками 🧺 10+ елементів
Кошик: Cylinder (⌀40) − Cylinder Hole (⌀36) + Half Torus (ручка). Серветка: Box червоний + білі смужки. Паска: Cylinder + Half Sphere + посипка. 3 писанки: Sphere різних кольорів.
⭐⭐⭐ Святковий стіл 🕯️ 15+ елементів
Стіл: Box + 4 ніжки. Скатертина: Box білий + червоні/чорні Box-смужки (вишиванка). Тарілка: Cylinder − Hole + 3 писанки. Паска на дошці + глазур. Свічка: Cylinder + Cone. Глечик: Cylinder − Hole + носик.
⭐⭐⭐⭐ Церква зі сценою 🏰 25+ елементів
Церква: Box + двосхилий дах + апсида (Half Cylinder). 5 куполів: Sphere + хрести. Арочні вікна: Box + Cylinder Hole. Дзвіниця: Cylinder + Cone + 4 арки. Огорожа + дерево.
