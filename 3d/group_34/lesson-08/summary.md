# Заняття 8: 🐣 Великдень в Україні
**Дата:** 07.04.2026
**Статус:** ✅ Створено

## Тема
Великодня тематика: складне моделювання українських великодніх символів. Кожне завдання — складна композиція з багатьма деталями.

## Нові концепції
- **Орнамент на криволінійній поверхні**: тонкі Cylinder як декор на Sphere
- **Hole + Group для складних форм**: порожнини, вікна, арки
- **Compose декількох Hole-операцій**: відняти кілька фігур одночасно
- **Складні композиції**: 8+ об'єктів у сцені
- **Дублювання по колу**: Ctrl+D з поворотом для симетричних елементів

## Що зробили

### ⭐ Завдання 1 — Розписана писанка на підставці 🥚
- Sphere як яйце, розтягнути (20×20×28 мм), червоний
- 3 горизонтальних Cylinder-смужки (⌀22, H=1, жовті)
- Маленькі ромбики (Box 3×3×1 повернутий 45°) між смужками ×6
- Зірочка зверху (2 тонких Box хрестом, повернути один 45°)
- Підставка: Ring (⌀16) або Cylinder (⌀14, H=3) з Cylinder-Hole

### ⭐⭐ Завдання 2 — Великодній кошик з дарунками 🧺
- Кошик: Cylinder (⌀40, H=25) − Cylinder Hole (⌀36, H=22) → порожнина
- Плетіння: 3 горизонтальних Torus (⌀40) обрізаних через Box-Hole
- Ручка: Half Torus або вигнутий Cylinder
- Серветка: тонкий Box (45×35×1), червоний, з білими смужками (тонкі Box)
- Паска: Cylinder (⌀18, H=20) + Half Sphere (глазур) + Sphere-посипка ×8
- 3 писанки (Sphere різних кольорів) у кошику поруч з паскою

### ⭐⭐⭐ Завдання 3 — Святковий стіл із вишиванкою 🕯️
- Стіл: Box (80×50×3) + 4 ніжки (Box 3×3×20 кожна)
- Скатертина-вишиванка: тонкий Box (85×55×0.5) білий + червоні/чорні тонкі Box як орнамент
- Тарілка з писанками: Cylinder (⌀30, H=3) − Cylinder Hole (порожнина) + 3 Sphere-писанки
- Паска на дошці: Box (дошка) + Cylinder + Half Sphere глазур + посипка
- Свічка у свічнику: Cylinder-свічник (⌀8, H=4) + Cylinder-свічка (⌀3, H=12) + Cone-вогонь
- Глечик: Cylinder − Cylinder Hole (порожнина) + тонкий Cylinder (носик)
- Сіль/перець: 2 маленьких Cylinder з Half Sphere зверху

### ⭐⭐⭐⭐ Завдання 4 — Великодня церква зі сценою 🏰
- Церква: Box стіни (40×30×25) + двосхилий дах (2 Box під кутом)
- Апсида: Half Cylinder прибудована ззаду
- 5-купольна група: центральний Sphere (⌀12) + 4 малих Sphere (⌀7) на кутах
- Хрести: 2 тонких Box хрестом на кожному куполі (5 штук!)
- Дзвіниця: Cylinder (⌀14, H=35) + Cone-дах + Half Sphere-дзвін + 4 арки (Box Hole)
- Вікна: 3 арочних вікна на фасаді (Box + Cylinder Hole зверху → арка)
- Двері: велика арка (Box + Half Cylinder Hole)
- Огорожа: Cylinder-стовпчики (×8) + Box-перекладини (×4)
- Дерево: Cone (крона зелена) + Cylinder (стовбур)

## Tinkercad фігури
