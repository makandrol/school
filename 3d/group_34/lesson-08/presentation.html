🏆 Сьогодні — найскладніші моделі! Багато деталей і Hole-операцій!

⭐ Завдання 1 — Розписана писанка 🥚

  1. Sphere → 20×20×28, червоний (яйце)
  2. 3 × Cylinder (⌀22, H=1, жовтий) — смужки
  3. 6 × Box (3×3×1, повернутий 45°) — ромбики між смужками
  4. Зверху: 2 тонких Box хрестом (1×6×1), один повернутий 45° → зірочка
  5. Підставка: Cylinder (⌀14, H=3) − Cylinder Hole (⌀10) → кільце
🎨 Підставка-кільце: великий Cylinder мінус маленький Cylinder Hole!

⭐⭐ Завдання 2 — Кошик з дарунками 🧺

🧺 Кошик (Hole-операція):

  1. Cylinder (⌀40, H=25, коричневий)
  2. Cylinder Hole (⌀36, H=22, підняти +4) → Group!
  3. Ручка: Half Torus зверху
  4. Серветка: тонкий Box (45×35×1, червоний) + 2 білих тонких Box-смужки

🍰 Вміст кошика:

  1. Паска: Cylinder (⌀18, H=20) + Half Sphere (глазур) + 8 × маленька Sphere (посипка)
  2. 3 писанки: Sphere розтягнуті, різних кольорів
💡 Всього 10+ елементів! Кошик = Cylinder − Hole!

⭐⭐⭐ Завдання 3 — Святковий стіл 🕯️

Елементи (15+):

  1. Стіл: Box (80×50×3) + 4 ніжки
  2. Скатертина-вишиванка: Box (85×55×0.5) білий + червоні та чорні тонкі Box-смужки як орнамент
  3. Тарілка: Cylinder (⌀30, H=3) − Cylinder Hole → 3 писанки всередині
  4. Паска на дошці: Box-дошка + Cylinder + Half Sphere глазур + посипка
  5. Свічка у свічнику: Cylinder (⌀8, H=4) + Cylinder (⌀3, H=12) + Cone (вогник)
  6. Глечик: Cylinder − Hole + тонкий Cylinder-носик
🕯️ Свічник = широкий короткий Cylinder. Вогонь = маленький Cone!

⭐⭐⭐⭐ Завдання 4 — Церква зі сценою 🏰

⛪ Церква (25+ елементів!):

  1. Стіни: Box (40×30×25) білий
  2. Дах: 2 Box під кутом → двосхилий
  3. 5 куполів: центральний Sphere (⌀12) + 4 малих (⌀7) на кутах
  4. 5 хрестів: по 2 тонких Box на кожному куполі
  5. Арочні вікна: Box + Cylinder Hole зверху ×3
  6. Двері: велика арка (Box + Half Cylinder Hole)

🔔 Дзвіниця + оточення:

  1. Cylinder (⌀14, H=35) + Cone-дах + дзвін
  2. 4 арки у дзвіниці (Box Hole ×4)
  3. Огорожа: 8 Cylinder-стовпчиків + 4 Box-перекладини
  4. Дерево: Cone (зелена крона) + Cylinder (стовбур)
🏆 Найскладніше! 5 куполів = центральний + 4 по кутах!

✅ Підсумки

  • ✅ Писанка — Sphere + смужки + ромбики + зірочка + підставка-кільце
  • ✅ Кошик — Hole-операція + ручка + серветка + паска + писанки (10+ елементів)
  • ✅ Святковий стіл — скатертина-вишиванка, тарілка, глечик, свічка (15+ елементів)
  • ✅ Церква — 5 куполів, арочні вікна, дзвіниця, огорожа, дерево (25+ елементів)
  • ✅ Закріпили: Hole + Group, складні композиції, багато деталей
