# Заняття 12: 🏰 Середньовіччя
**Дата:** 05.05.2026
**Статус:** ✅ Створено

## Тема
Середньовічна тематика: зброя, обладунки та фортеця. Різноманітні техніки — симетрія, дзеркальне відображення, складні Hole-операції для орнаментів.

## Нові концепції
- **Симетрія**: моделюємо половину → Ctrl+D → дзеркально відобразити (масштаб −100% по одній осі)
- **Орнамент через Hole**: вирізання візерунку на плоскій поверхні
- **Складання зі зміщенням**: деталі що частково перекривають одна одну (лускатий шолом)

## Що зробили

### ⭐ Завдання 1 — Щит лицаря 🛡️
- Основа: Cylinder сплющений (⌀40, H=4) або Box із закругленими кутами
- Окантовка: Torus (⌀42) обрізаний навпіл (нижню половину Box Hole) — бордюр
- Герб: вирізи через Hole — хрест (2 × Box Hole) або зірка (3 × Box Hole під 60°)
- Центральний елемент: Sphere (⌀8) або Cone (⌀6) — металевий бос
- Ручка ззаду: Box (20×3×3) — тримач
- Розмальовка: верхня половина одного кольору, нижня — іншого
- ~10 елементів

### ⭐⭐ Завдання 2 — Лицарський меч ⚔️
- Лезо: Box (4×1.5×40) сірий/металік — довге і тонке
- Вістря: Wedge або Cone зверху леза (загострення)
- Дол (жолобок): Box Hole тонкий (2×0.5×30) — вирізати канавку по центру леза
- Гарда (хрестовина): Box (20×2×3) перпендикулярно — захист руки
- Рукоять: Cylinder (⌀3, H=10) коричневий, під гардою
- Навершя: Sphere (⌀4) або Cylinder знизу рукояті
- Оздоба гарди: 2 × Sphere (⌀2) на кінцях
- ~12 елементів

### ⭐⭐⭐ Завдання 3 — Шолом лицаря ⛑️
- Купол: Half Sphere (⌀30) сірий — верх шолома
- Забрало: Box (15×12×1) з отворами для очей (2 × Box Hole горизонтальні вузькі)
- Щілини забрала: 4–5 × Box Hole тонкі горизонтальні — для дихання
- Гребінь: Box (2×15×8) зверху по центру — прикраса
- Назатильник: Box (15×8×1) ззаду, нахилений — захист шиї
- Вушні пластини: 2 × Box (6×8×1) з боків
- Вінтики/заклепки: 4 × Cylinder (⌀1.5, H=1) — декор
- ~18 елементів

### ⭐⭐⭐⭐ Завдання 4 — Середньовічний замок 🏰
- Основна стіна: Box (60×5×25) сірий
- Зубці: 5 × Box (5×5×5) зверху стіни (через рівні проміжки)
- Башта ліва: Cylinder (⌀14, H=35) — вища за стіну
- Башта права: Cylinder (⌀14, H=35)
- Конічні дахи: 2 × Cone (⌀16, H=10) на верхівках башт
- Ворота: Box Hole з арочним верхом (Half Cylinder Hole зверху + Box Hole знизу)
- Решітка: 3 × Cylinder (⌀0.5, H=12) вертикальні у воротах
- Вікна-бійниці: 4 × Box Hole (1×1×4) — вузькі вертикальні вирізи
- Прапор: Box (6×0.5×4) + Cylinder (⌀0.5, H=8) — на одній з башт
- Міст: Box (15×8×1) перед воротами
- ~30 елементів
