Заняття 12 — лицарі, мечі та замки!

🆕 Нові прийоми

Орнамент через Hole:

Красивий візерунок = вирізи на поверхні!

💡 Хрест на щиті = 2 Box Hole (вертикальний + горизонтальний) → Group!

Арка для воріт:

Box Hole (прямокутник) + Half Cylinder Hole (арка зверху) = красиві ворота!

Зубці стіни:

Рівномірно розставлені Box зверху стіни. Однакові відстані!

⚠️ Щоб зубці були рівномірні — рахуй позицію кожного!

⭐ Завдання 1 — Щит лицаря 🛡️

Щит з гербом! ~10 елементів

Крок за кроком:

1 Cylinder ⌀40, H=4, сплющений → основа щита
2 Torus ⌀42 − Box Hole (низ) → бордюр
3 Герб: 2× Box Hole (хрест) або 3× під 60° (зірка)
4 Sphere ⌀8 по центру → металевий бос
5 Box 20×3×3 ззаду → ручка
6 Пофарбувати: верх — червоний, низ — синій!

⭐⭐ Завдання 2 — Лицарський меч ⚔️

Довгий меч з гардою та рукояткою! ~12 елементів

Крок за кроком:

1 Box 4×1.5×40, сірий → лезо
2 Wedge або Cone → вістря зверху
3 Box Hole 2×0.5×30 → дол (канавка по центру)
4 Box 20×2×3 → гарда (перпендикулярно)
5 Cylinder ⌀3, H=10, коричневий → рукоять
6 Sphere ⌀4 → навершя знизу
7 2× Sphere ⌀2 → оздоба на кінцях гарди
Дол (канавка) робить меч легшим і красивішим! Це тонкий Box Hole по центру леза.

⭐⭐⭐ Завдання 3 — Шолом лицаря ⛑️

Шолом із забралом та гребенем! ~18 елементів

Крок за кроком:

1 Half Sphere ⌀30, сірий → купол
2 Box 15×12×1 спереду → забрало
3 2× Box Hole (горизонт., вузькі) → щілини для очей
4 4× Box Hole тонкі → щілини для дихання
5 Box 2×15×8 зверху → гребінь
6 Box 15×8×1 ззаду (нахил) → назатильник
7 2× Box 6×8×1 з боків → захист вух
8 4× Cylinder ⌀1.5, H=1 → заклепки-декор
💡 Забрало — це Box з багатьма Box Hole! Щілини = вирізи для повітря.

⭐⭐⭐⭐ Завдання 4 — Середньовічний замок 🏰

Замок з вежами, зубцями та воротами! ~30 елементів

Конструкція:

1 Box 60×5×25 → стіна
2 5× Box 5×5×5 → зубці зверху
3 2× Cylinder ⌀14, H=35 → вежі (ліва+права)
4 2× Cone ⌀16, H=10 → дахи башт
5 Box Hole + Half Cyl Hole → арка воріт
6 3× Cylinder ⌀0.5 → решітка
7 4× Box Hole 1×1×4 → бійниці
8 Прапор: Box + Cylinder на башті
9 Box 15×8×1 → підйомний міст
⚠️ Арка воріт = Box Hole (прямокутник знизу) + Half Cylinder Hole (напівкруг зверху). Разом Group!
