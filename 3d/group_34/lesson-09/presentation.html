⭐ Завдання 1 — Паркова лавочка 🪑

  1. Сидіння: Box (40×15×2), коричневий
  2. Спинка: Box (40×2×12), коричневий → нахили назад на ~10°
  3. 2 ніжки: Box (2×15×10), чорні, по краях
  4. 2 підлокітники: Box (2×12×6), чорні, по боках
  5. Рейки: 3 тонких Box (38×1×0.5) на сидінні → щілини між дошками
💡 Спинку нахиляємо: виділи Box → обертання → трохи назад (~10°)!

⭐⭐ Завдання 2 — Квітка у вазоні 🌷

🪴 Вазон (Hole!):

  1. Cylinder (⌀20, H=15), теракотовий
  2. Cylinder Hole (⌀16, H=12, +4мм) → Group!
  3. Cylinder (⌀15, H=2) коричневий = земля

🌷 Квітка:

  1. Cylinder (⌀2, H=25) зелений — стебло
  2. 2 × Sphere (8×2×5) зелені — листки
  3. Sphere (⌀6) жовта — серединка квітки
  4. Sphere (8×3×8) рожева — 1-ша пелюстка
  5. Ctrl+D → повернути 72° → повторити 4 рази = 5 пелюсток!
🌸 72° = 360° ÷ 5! Для 6 пелюсток було б 60°!

⭐⭐⭐ Завдання 3 — Фонтан 🌊

Басейн та стовп:

  1. Cylinder (⌀50, H=5) — основа
  2. Cylinder Hole (⌀46, H=4, +1.5мм) → Group → басейн!
  3. Cylinder (⌀8, H=25) по центру — стовп
  4. Cylinder (⌀45, H=3) блакитний = вода в басейні

Верхня чаша + струмені:

  1. Cylinder (⌀20, H=4) − Cylinder Hole (⌀16, H=3) → чаша
  2. Cylinder (⌀15, H=2) блакитний = вода в чаші
  3. 4 × Cylinder (⌀1, H=8) блакитні, нахилені назовні ≈20°
💧 Воду роби трохи прозорою (Tinkercad → колір → Transparent)!

⭐⭐⭐⭐ Завдання 4 — Дитячий майданчик 🎠

🛝 Гірка:

  1. Box (10×30×20) — вежа
  2. Box (10×40×2) під кутом 30° — з'їзд
  3. 4 × Box (10×5×5) ступінчасто — сходинки

🪁 Гойдалка:

  1. 2 × Cylinder (⌀2, H=20) — стійки (▲-форма)
  2. Cylinder (⌀2, H=25) горизонтально — перекладина
  3. Box (20×3×1) — сидіння + 2 Cylinder-мотузки

🏖️ Пісочниця:

  1. Box (30×30×5) − Box Hole (26×26×4) → борти
  2. Cylinder (⌀28, H=3, жовтий) = пісок
  3. Лопатка: Box + Cylinder
🏆 Найскладніше! Гірка + гойдалка + пісочниця = цілий майданчик!

✅ Підсумки

  • ✅ Лавочка — Box-конструкція, нахил спинки

  • ✅ Дитячий майданчик — складна сцена з 3 об'єктами
