# Заняття 9: 🌳 Весняний парк
**Дата:** 14.04.2026
**Статус:** ✅ Створено

## Тема
Весняна тематика: моделювання елементів міського парку. Складні об'єкти з кількома Hole-операціями та деталями.

## Нові концепції
- **Torus** як повноцінна форма (кільце гойдалки, обідок фонтану)
- **Дублювання з поворотом** (Ctrl+D → повернути на 90° → повторити) для пелюсток квітки
- **Складна Hole-операція**: кілька Hole-фігур за один Group
- **Симетрія**: дублювання + дзеркальне відображення

## Що зробили

### ⭐ Завдання 1 — Паркова лавочка 🪑
- Сидіння: Box (40×15×2), коричневий
- Спинка: Box (40×2×12), коричневий, нахилена назад (~10°)
- 2 ніжки: Box (2×15×10) чорні, по краях
- 2 підлокітники: Box (2×12×6) чорні
- Деталь: тонкі Box-рейки (3 штуки) на сидінні (щілини між дошками)

### ⭐⭐ Завдання 2 — Квітка у вазоні 🌷
- Вазон: Cylinder (⌀20, H=15) − Cylinder Hole (⌀16, H=12) → порожній горщик
- Земля: Cylinder (⌀15, H=2), коричневий, всередині
- Стебло: Cylinder (⌀2, H=25), зелений
- Листки: 2 × Sphere (сплюснута, 8×2×5), зелені, по боках стебла
- Квітка: 5 пелюсток (Sphere 8×3×8, рожеві) по колу + серединка (Sphere ⌀6, жовта)
- Пелюстки через Ctrl+D: перша пелюстка → Ctrl+D → повернути 72° → повторити 4 рази

### ⭐⭐⭐ Завдання 3 — Фонтан 🌊
- Основа: Cylinder (⌀50, H=5) − Cylinder Hole (⌀46, H=4) → басейн
- Стовп: Cylinder (⌀8, H=25) по центру
- Верхня чаша: Cylinder (⌀20, H=4) − Cylinder Hole (⌀16, H=3)
- Вода в басейні: Cylinder (⌀45, H=3), блакитний, напівпрозорий
- Вода у чаші: Cylinder (⌀15, H=2), блакитний
- Струмені: 4 × Cylinder (⌀1, H=8) блакитні, нахилені назовні під 20°
- Бордюр: Torus (⌀52) обрізаний до половини висоти (Torus + Box Hole знизу)

### ⭐⭐⭐⭐ Завдання 4 — Дитячий майданчик 🎠
- Гірка: Box (10×30×20) + Box під кутом 30° (з'їзд) + Cylinder (бортики)
- Сходинки: 4 × Box (10×5×5) ступінчасто
- Гойдалка: 2 × Cylinder (⌀2, H=20) — стійки + Box (20×3×1) — сидіння + 2 × Cylinder (⌀1, H=15) — тримачі
- Перекладина: Cylinder (⌀2, H=25) горизонтально зверху
- Пісочниця: Box (30×30×5) − Box Hole (26×26×4) → борти + Cylinder (⌀28, H=3, жовтий) = пісок
- Лопатка: маленький Box + Cylinder (ручка)
- Паркан: 6 × Cylinder (⌀1, H=8) + 2 × Box (30×1×1) горизонтально
